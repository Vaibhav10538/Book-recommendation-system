# 📚 Book Recommendation Web App

Content-Based Book Recommendation System using TF-IDF + KNN.

## Folder structure

```text
book_recommendation_web/
├── app.py
├── books_1.Best_Books_Ever.csv
└── requirements.txt
```

## Run

Open terminal in this folder:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The browser will open the web application automatically.
